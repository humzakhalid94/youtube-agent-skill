# Bobo Characters

Use this skill to create or update the Bobo & Friends character bible and character reference prompts.

## Source of truth
Read `character-bible/CHARACTERS.md` before defining a character. Read `character-bible/VISUAL-STYLE.md` for the shared art direction.

## Canonical character names currently established
- Bobo — bear hero
- Mimi Mani
- Kiki Mani
- Hariko — elephant
- Pande Panda
- Peepo — chick
- A monkey (name not yet confirmed)
- A bunny (name not yet confirmed)

Do not silently change spelling, merge characters, or treat proposed details as confirmed facts.

## Character design process
For each character, separate:
1. Confirmed canon supplied by the channel owner.
2. Proposed design choices that need approval.
3. Production constraints for keeping the design stable.

A useful character profile includes:
- Name and species
- Story role and personality
- Body silhouette and proportions
- Face, eyes, muzzle/beak, ears, and distinctive markings
- Main colours and clothing/accessories
- Typical expressions and gestures
- Relative scale compared with Bobo
- Prompt anchor: concise details that should appear in every image prompt
- Negative constraints: details that must not change

## Consistency rules
- Preserve the same species, silhouette, colours, facial features, clothing, and proportions across scenes.
- Avoid adding accessories in one scene and removing them in another unless the story explicitly shows the change.
- Avoid vague phrases such as "same character" as the only continuity instruction. Repeat the important visual anchors in each scene prompt.
- Do not assume generated images will remember previous images. Recommend using approved reference images or image-reference features when the chosen image provider supports them.
- Do not claim a reference image has been created or saved unless the user has supplied or approved one.

## Output
Provide a character sheet, a reusable prompt anchor, a negative prompt / consistency checklist, and a list of unresolved owner decisions. Update the bible only when the user explicitly asks to establish or change canon.
