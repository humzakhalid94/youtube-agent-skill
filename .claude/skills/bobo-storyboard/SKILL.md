# Bobo Storyboard

Create a scene-by-scene visual plan from the approved script.

## Before starting
Read:
- `character-bible/CHARACTERS.md`
- `character-bible/VISUAL-STYLE.md`
- `templates/storyboard-template.md`

If character details are not confirmed, preserve them as explicit assumptions.

## Storyboard rules
- Default to 8–10 scenes for a 30–40 second Short.
- Keep each scene visually readable on a phone.
- Use vertical 9:16 framing unless the user requests another format.
- Each scene should communicate one main action or emotional beat.
- Describe screen direction, character position, foreground/background, facial expression, and important props.
- Maintain geography and prop continuity between adjacent scenes.
- Do not add text inside generated images unless the user specifically requests it. Plan captions separately.
- Include a clear opening image and a satisfying final image.
- Use child-safe, non-threatening staging.

## Output
Produce:
1. Episode metadata and total runtime.
2. A storyboard table with scene number, time range, shot size, camera angle/movement, setting, character blocking, action, expression, props, transition, and continuity notes.
3. A list of assets required (characters, backgrounds, props).
4. A continuity audit: character appearance, prop state, screen direction, time of day, and location.
5. Any unresolved assumptions.

Timing must be continuous and add up to the approved runtime. Do not alter dialogue or story events without flagging the change.
