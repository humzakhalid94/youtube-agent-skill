# Bobo Script

Write a production-ready short script from an approved Bobo & Friends story.

## Defaults
- Target duration: 30–40 seconds.
- Target scene count: 8–10.
- Language: clear, simple English unless the user requests another language.
- Audience: children and families; keep language warm, concrete, and easy to translate.
- Use short sentences and natural spoken phrasing.
- Keep dialogue sparse so the story remains understandable internationally.

## Requirements
- Preserve the approved story. Do not introduce new plot turns or characters without permission.
- Give the opening a visual or emotional question within the first 1–3 seconds.
- Each scene must change the action, reveal information, or advance the emotion.
- Make the cause and effect obvious.
- End with a clear visual payoff, not a long explanation.
- Do not use manipulative urgency, misleading promises, or frightening hooks.
- Do not write lyrics from existing songs or imitate a known character's voice.

## Output format
Start with:
- Episode title
- Target duration
- Estimated spoken word count
- Character list

Then provide a table with:
| Scene | Time | Visual action | Narration | Dialogue | Audio / SFX |

Timing must add up to the target duration. Keep narration and dialogue short enough to speak naturally in the allotted time. If the script is too dense, simplify it rather than asking the voice actor to speak unnaturally fast.

Finish with:
- On-screen text (if any)
- Gentle takeaway (optional; preferably shown visually)
- Continuity notes
- Questions / assumptions

If a story has not been approved, state that the script is a draft.
