# Claude Code Project Instructions — Bobo & Friends

This repository contains the original YouTube channel skills and a custom Bobo & Friends production workflow.

## Project priorities
- Preserve all original upstream skills and utilities unless the owner explicitly asks to change them.
- Use the Bobo-specific skills in `.claude/skills/` for children's animation production.
- Read `character-bible/CHARACTERS.md` and `character-bible/VISUAL-STYLE.md` before creating character or image prompts.
- Use `templates/episode-brief.md`, `templates/storyboard-template.md`, and `templates/production-checklist.md` as reusable production documents.

## Channel defaults
- Recurring hero: Bobo, a bear.
- Target format: 30–40 second vertical YouTube Shorts.
- Typical storyboard: 8–10 scenes.
- Visual direction: cute, polished 3D cartoon, warm and expressive.
- Audience: children and families; keep stories gentle, clear, inclusive, and age-appropriate.
- Default writing language: simple English, unless the owner asks for another language.

## Canon and approvals
- Treat the character bible as the source of truth.
- Never silently rename a character or invent approved canon.
- Clearly label creative proposals and ask before adding them to canon.
- Get owner approval before changing an approved story or script.
- Never claim media has been generated, rendered, uploaded, or published unless the relevant operation actually happened.

## Production boundaries
- Skills in this repository write creative plans, scripts, prompts, and checklists. They do not inherently provide image generation, video animation, rendering, or YouTube upload capability.
- Do not publish or schedule content automatically.
- The channel owner must review the final video, audio, captions, metadata, audience designation, and any applicable synthetic/altered-media disclosures before upload.
- Do not invent analytics, performance figures, licences, or production facts.
